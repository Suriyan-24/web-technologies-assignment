Question 01 • CO1

World Wide Web Fundamentals

Illustrated overview of the Internet, networks, URLs, domains, browsers, servers and website operation.

Internet Overview

What is the Internet?

The Internet is a global network of interconnected computer networks that communicate using standard protocols such as TCP/IP.

Example: Your browser, Wi-Fi router, ISP and a web server work together to deliver a webpage.

Network Concepts

How devices communicate

Devices use addresses and protocols to exchange data. IP identifies hosts at the network layer, while ports identify application services.

Key terms: IP address, MAC address, router, switch, DNS, TCP/UDP and HTTP/HTTPS.

Domain Name

Human-friendly identity

A domain name provides a memorable name for a network service. DNS translates names into IP addresses so clients can locate servers.

Example: example.com

URL Structure

Breaking down a URL

https://www.example.com/courses/web?id=501#overview

Scheme: protocol used • Domain: host name • Path: requested resource • Query: parameters • Fragment: location within a document.

Web Browser

Client software such as a browser sends HTTP/HTTPS requests and interprets returned HTML, CSS and JavaScript to render a webpage.

Web Server

A web server receives requests, locates or generates resources, and sends responses to clients. Server-side applications may also access databases.

Working Principle

Enter URL → DNS resolution → connection → HTTP request → server processing → HTTP response → browser parses and renders the page.

Client-side vs Server-side Scripting

Client-sideServer-side
Runs mainly in the user's browser.Runs on the web server.
JavaScript is the primary browser scripting language.Can use technologies such as Node.js, Java, Python, PHP, etc.
Used for UI interaction and dynamic page behaviour.Used for business logic, authentication, database access and APIs.
Source code is generally delivered to the client.Implementation remains on the server; client receives the response.
